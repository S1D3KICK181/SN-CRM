# SN Practice CRM presentation

Open `index.html` in a browser. Use the arrow keys, Page Up / Page Down, or the on-screen controls to navigate.

To export a PDF, print from the browser and choose **Save as PDF**. The print stylesheet places one 16:9 slide on each page.

The leadership dashboard slide uses `../.impeccable/review/desktop.png`, so keep the presentation folder in the project when presenting or exporting.
